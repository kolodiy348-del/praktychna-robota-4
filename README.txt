ПРАКТИЧНА РОБОТА №3 — Flask + SQLite

Потрібно: Python 3.10+ та інтернет лише для першого встановлення Flask.

Windows:
1. Розпакуйте ZIP повністю.
2. Запустіть start_windows.bat (або відкрийте термінал у цій папці).
3. Введіть пароль адміністратора, коли програма попросить.
4. Відкрийте http://127.0.0.1:5000 у браузері (НЕ відкривайте index.html як file://).
5. Заповніть форму та натисніть «Надіслати повідомлення».
6. Перейдіть на http://127.0.0.1:5000/messages, введіть пароль.
7. Перевірте список повідомлень і видалення.

Ручний запуск у PowerShell:
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
$env:ADMIN_PASSWORD="MyStrongPassword123"
$env:SECRET_KEY="ChangeThisToRandomLongSecret"
.venv\Scripts\python server.py

SQLite-база messages.db створюється автоматично під час запуску.
SQL використовує параметризовані запити (?), щоб уникати SQL-ін'єкцій.
GET /api/messages і DELETE /api/messages/<id> доступні тільки адміністратору.
POST /api/messages приймає JSON {name,email,message}, повертає 201 та id.
Сторінка /messages показує дані з бази, дозволяє видаляти їх без перезавантаження.

УВАГА: сервер призначений для локального навчального запуску, не для публічного розміщення.
Не додавайте паролі, SECRET_KEY або особисті повідомлення до ZIP.
Для демонстрації зробіть скриншоти форми, успішного збереження та сторінки /messages.
